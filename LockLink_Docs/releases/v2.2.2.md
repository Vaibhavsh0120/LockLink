# LockLink v2.2.2

Source version **2.2.2+222**.

## Changes

- Shorten the relay and indicator release pulse from 1,000 ms to 500 ms.
  The independent timer cutoff and protection against duplicate commands remain.
- Report `duration_ms: 500` in successful unlock responses and update the
  isolated-pulse diagnostic tool and current setup documentation.
- Synchronize app, firmware, and iOS widget version metadata to 2.2.2+222.

## Verification

All nine native firmware suites, four host-tool tests, nine version-metadata
tests, and the version consistency check passed. The ESP32-C3 firmware build
and image verification also passed. Timing tests cover active output at
499 ms, cutoff at 500 ms, duplicate commands, and clock rollover.

The firmware has not been uploaded for this change. Physical relay/door timing
and mobile builds have not been verified for v2.2.2. The previously documented
intermittent packet loss remains unresolved; this duration change does not
address it.
