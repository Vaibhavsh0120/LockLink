# LockLink v1.5.0

## Interface

- Warm neutral light theme and charcoal dark theme, aligned with native widgets.
- Focused door control with one status label, a clear Unlock door action, and a connection shortcut.
- Visible progress while checking the connection.
- Compact device settings, grouped preferences, and shorter widget setup guidance.
- Two-column settings on wider screens and wrapping appearance controls for large text.
- Updated web app title, description, and launch colors.

## Version

App: `1.5.0+15`. The iOS widget extension also uses version `1.5.0`, build `15`.

Device protocol, local Wi-Fi requirements, pairing, and unlock restrictions are unchanged.
The interface reports controller state, not physical door position.

## Validation

See the task handoff for checks performed. iOS builds and physical device testing
require their respective environments; this Windows UI refresh does not certify them.
