# LockLink v2.2.0

Source version **2.2.0+220**.

## Changes

- Completely remove Matter/Bluetooth integration, smart-home screens, setup QR
  dependencies, platform home-app handoffs, and the network/app Terminal.
- Keep the existing app and native widget status/challenge/unlock protocol.
  USB-only STATUS and WIFI RECONNECT diagnostics retain no log history.
- Use one ESP-IDF Wi-Fi owner with bounded retry backoff, DHCP recovery, and
  listener restart after network events/address changes. Preserve saved Wi-Fi.
- Bound HTTP idle/header/body waits and allocations in a project-local copy of
  the pinned WebServer. Protect fragmented legitimate requests and the absolute
  deadline when a CR arrives without its LF. Limit pending clients and close
  completed sockets explicitly.
- Add heap, allocation, reset, uptime, temperature, loop/stack, Wi-Fi event and
  HTTP diagnostics; configure an eight-second loop watchdog. Preserve the
  independent one-second output cutoff, polarity and one-use authentication.
- Allow explicit private browser-origin lists for local testing; no relay-mode
  wildcard CORS or authentication bypass.

## Verification

Firmware build/image verification, eight native firmware suites, 32 Flutter
tests, Flutter analysis/web build and nine metadata tests passed. Live checks
passed sixteen HTTP boundary cases, exact local-origin preflights, five
deliberate reconnects, and inert USB flooding while HTTP remained responsive.

**Residual intermittent packet loss is still reproduced on this physical board.**
Short four-client tests passed, but longer and alternate-radio trials failed,
including a one-client SDK-default run with 12 failures in 344.9 seconds despite
healthy heap and no restart. Failed experiments were rejected. This release
does not claim the offline problem is fully solved or certify permanent use.

See the [dated investigation](../RELIABILITY_2026-10-02.md) for measurements,
rejected trials and the next cable/power/board comparison. No 24-hour run was
performed; the user capped sessions at 15 minutes. Watchdog hang injection,
electrical pin timing, actual installed relay/lock behavior, and iOS compilation
were not verified. The user separately confirms working Android widgets and
the iOS app in LiveContainer; those paths were left intact.
