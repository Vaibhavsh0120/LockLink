# LockLink v2.2.5

Source version **2.2.5+225**.

## Changes

- **Hardware**: Switched to the [Single 3V Relay (SRD-DC03V-SL-C)](https://robu.in/product/single-3v-relay-isolated-drive-control-module/), a high-level trigger module powered from the ESP32-C3's 3.3 V rail.
- **Signal polarity**: GPIO4 is now LOW at idle and HIGH for the 1.5-second release pulse (`outputActiveHigh = true`). The relay is de-energized at idle and energizes during the pulse (fail-secure with NO contact).
- **Wiring**: The 10 kΩ bias resistor changes from a pullup (to 3.3 V) to a pulldown (to GND) to match the new idle LOW state during boot.
- **Documentation**: README, relay setup, and ESP32-C3 setup guides updated with product links for the [ESP32-C3 SuperMini](https://robu.in/product/esp32-c3-development-board-esp32-supermini/) and the relay module, new wiring diagram, and corrected polarity references.

## Verification

- Native test suites (8/8) pass with the updated signal polarity.
- LED-only and relay output tests confirm correct idle/pulse levels.
- Firmware compiles for the `esp32-c3-supermini` environment.
- Physical relay trigger, boot bias, and power-loss behavior should be verified on the bench before permanent installation.
