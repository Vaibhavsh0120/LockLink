# LockLink v2.2.3

Source version **2.2.3+223**.

## Changes

- Set the opening/release pulse to two seconds (2000 ms), with the same
  independent timer cutoff for the relay and blue LED.
- Return `duration_ms: 2000` from successful `/unlock` requests and align the
  diagnostic release-cycle wait with the two-second cutoff.
- Update timing checks, active setup guides, and synchronized release metadata.
  Repeated commands during an active pulse still do not extend the release.

## Verification

- Nine native firmware suites passed, including relay/LED cutoff at 2000 ms,
  active state at 1999 ms, duplicate commands, and timer wraparound.
- Four host-tool tests and nine version/release tests passed.
- ESP32-C3 Super Mini firmware build and image verification passed: 4 MB
  layout, correct chip, current factory contents, and erased factory NVS.
- Version synchronization, release metadata validation, and `git diff --check`
  passed.

Firmware was not uploaded. Physical relay/door timing and live HTTP behavior
were not verified. No local mobile builds were run; publication requires the
release workflow's Android and iOS checks. The previously recorded
intermittent packet loss remains outside this timing fix; see the
[dated investigation](../RELIABILITY_2026-10-02.md).
