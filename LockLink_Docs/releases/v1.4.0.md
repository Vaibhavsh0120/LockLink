# LockLink v1.4.0 — Gate widgets

Changes since v1.3.1:

- Android Home Screen widget with an Unlock gate action and request feedback.
- Compact Android 1×1 circle and 2×1 pill options, light/dark surfaces, and full
  request feedback after tapping. Existing widgets can be resized or re-added.
- iPhone Home Screen, Today View and Lock Screen interactive widget extension
  using WidgetKit/App Intents (iOS 17+ APIs, including iOS 27).
- Circular small and pill-shaped medium iPhone layouts, plus compact Lock Screen
  controls. Home Screen grid sizes remain controlled by iOS.
- Native widget actions use the saved gate address and authenticated pairing
  protocol without opening the app. Settings includes widget setup/update.
- Protected native credential storage, duplicate-request guards, short request
  expiry and no automatic unlock retries.
- App version 1.4.0, build 14.

The existing Light/Dark/System themes, haptics, editable device defaults, relay
support and one-time serial connection details remain available.

Widgets need access to the gate's local Wi-Fi network. iPhone widgets require a
directly installed app with its signed widget extension and shared App Group;
they are unavailable when LockLink runs as a guest inside LiveContainer.

Android APKs remain test-signed. The iOS IPA is unsigned and needs both the app
and extension signed before installation. Device-specific widget behavior and
physical unlocking must be verified on a phone; packaging a widget is not
evidence of on-device operation.

Release history checked against GitHub:
v1.0.0 local controller; v1.1.0 relay; v1.2.0 haptics; v1.3.0 settings/defaults;
v1.3.1 serial connection details.
