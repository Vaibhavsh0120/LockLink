# LockLink v2.2.4

Source version **2.2.4+224**.

## Changes

- Set the opening/release pulse to 1.5 seconds (1500 ms), replacing the
  two-second duration published in v2.2.3. The previous change was reverted
  before applying this correction.
- Return `duration_ms: 1500` from successful `/unlock` requests and wait
  1.7 seconds before diagnostic cutoff checks.
- Synchronize release metadata and active documentation. Preserve the
  independent relay/LED cutoff and rejection of commands during a pulse.

## Verification

- Nine native firmware suites passed, including active output at 1499 ms,
  cutoff at 1500 ms, duplicate commands, and timer wraparound.
- Four host-tool tests and nine version/release tests passed.
- ESP32-C3 Super Mini build and firmware image verification passed.
- Version synchronization, release metadata validation, and `git diff --check`
  passed.

Firmware was not uploaded. Physical relay/door timing and live HTTP behavior
were not verified. No mobile builds were run for this correction. The existing
intermittent packet-loss investigation remains outside this timing change.
